## 👋 Welcome

This is my personal portfolio — a small world of mine on the web. Instead of a plain list of projects, you get an interactive experience: a glowing 3D "neural core" you can grab and orbit, a cinematic loading sequence, smooth scrolling throughout, and a fully working contact form.

Best experienced on a desktop with your sound of choice in the background. 🎶

## ✨ Things to try

| | |
|:--|:--|
| 🧠 **The Neural Core** | On the landing page — a living 3D orb. **Grab it and drag** to orbit around; it never stops breathing. |
| 🖱️ **Custom cursor** | Your cursor grows into an orange dot over anything clickable. Coordinates included, because why not. |
| 🌐 **Language toggle** | Top-right corner. Everything switches between **English** and **Deutsch** — even the German punctuation vibes. |
| 💳 **Business cards, reimagined** | Projects open like case files; skills are presented as a "Capability Matrix". |
| 📬 **The Contact Portal** | A real, working message form — no mailto: popups required. You'll get a transmission-confirmed confirmation. |
| ⬇️ **CV download** | Grab my latest CV straight from the hero section. |

**Stack at a glance:** React 19 · Vite · Tailwind CSS 4 · Three.js (react-three-fiber) · Framer Motion · GSAP · Lenis

**Run it locally**

```bash
git clone https://github.com/Harshil-0011/My-Portfolio.git
cd My-Portfolio
npm install
npm run dev      # development server
npm run build    # production build (outputs to ./docs)
```

**Deploying to GitHub Pages**

> ⚠️ This project builds with **GitHub Actions** (`.github/workflows/deploy.yml`). Make sure your repo is set to deploy from **Settings → Pages → Source: GitHub Actions** — otherwise the site will break with MIME type errors. The build runs automatically on every push to `main`.
